# Blog content

Add one HTML fragment per article, named `<slug>.html`, and its metadata to `../posts.json` when ready to publish. The fragment contains the article body only, starting with paragraphs or an `h2`; the shared template supplies the title, author, published date, category, and summary. The optional `author` field defaults to the site owner's name.

See the root README for the metadata format and publishing steps. Presentation posts use PDF assets under `assets/slides/` and include a version note with links to peer-reviewed journal articles. Keep that distinction when adding presentations, and use the presentation date as the published date for conference, defence, and exam posts so readers can cite them. Use the actual publication date for other posts. The `Defence or exam` category appears as “Defence & exam slides” in the Blog filter.
